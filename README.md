# Guinda-Smash-Multipagina
La multipagina del guinda smash, el qr redirecciona a esta y esta da al start.gg y a la cumnidad de wasap

## Publicar en GitHub Pages
1. Ve a **Settings > Pages** en el repositorio.
2. En **Source**, selecciona **GitHub Actions**.
3. Haz push a `main` y el workflow `Deploy to GitHub Pages` publicará el sitio automáticamente.
